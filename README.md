# Automated Market Research Platform

A portfolio project demonstrating a Django REST API, PostgreSQL data model, Next.js client, and WebSocket-based research progress updates.

## Highlights

- Research brief creation and tracking
- Market and evidence/source records
- REST API architecture with Django REST Framework
- Real-time progress updates over WebSockets
- Report/status workflow designed for long-running research jobs
- PostgreSQL-ready configuration

## Stack

- Backend: Python, Django, Django REST Framework
- Frontend: Next.js, React
- Database: PostgreSQL
- Realtime: WebSockets

## Project structure

```text
backend/   Django API and domain services
frontend/  Next.js application
```

## Note

This repository is a portfolio/demo implementation designed to demonstrate the engineering patterns used in a market-research workflow. It does not contain proprietary employer code or data.
